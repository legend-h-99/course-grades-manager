# Sanad - سند لإدارة الدرجات

تطبيق ويب عربي لإدارة درجات مقرر تدريبي مشترك بين أكثر من مدرب. يهدف التطبيق إلى تسهيل إنشاء مساحة عمل للمقرر، مشاركة رمز المقرر مع المدربين الآخرين، إضافة المتدربين، بناء الاختبارات والتقييمات، رصد الدرجات، ثم تصدير النتائج في ملف Excel.

## هدف البرنامج

البرنامج مخصص للمدربين الذين يحتاجون إلى إدارة مقرر واحد بصورة مشتركة، خصوصًا عندما يكون للمقرر أكثر من مدرب أو أكثر من شعبة نظرية/عملية. بدل أن يحتفظ كل مدرب بملف منفصل، يوفر التطبيق مساحة واحدة مرتبطة برمز مقرر فريد يستطيع أكثر من مدرب الانضمام إليها والعمل على نفس بيانات المقرر.

## المشكلة التي يحلها

- تشتت الدرجات بين ملفات متعددة.
- صعوبة مشاركة بيانات المقرر بين أكثر من مدرب.
- الحاجة إلى ربط المتدربين بالشعب النظرية أو العملية.
- الحاجة إلى حساب المجموع النظري والعملي والإجمالي بسرعة.
- الحاجة إلى تصدير كشف درجات منسق يمكن تسليمه أو أرشفته.

## أهم الميزات

- تسجيل حساب مدرب وتسجيل الدخول.
- حفظ بيانات الكلية والقسم والتخصص.
- إنشاء مقرر برمز فريد.
- مشاركة رمز المقرر مع مدرب آخر.
- انضمام أكثر من مدرب إلى نفس المقرر عبر الرمز.
- عرض قائمة مدربي المقرر المرتبطين.
- إضافة المتدربين يدويًا.
- استيراد المتدربين من ملفات CSV أو Excel.
- إنشاء اختبارات أو تقييمات نظرية وعملية.
- رصد الدرجات لكل متدرب ولكل تقييم.
- حساب مجموع النظري والعملي والإجمالي.
- البحث عن بطاقة متدرب بسرعة.
- حفظ واستدعاء البيانات من مساحة آمنة مرتبطة بالحساب.
- تصدير كشف الدرجات إلى ملف Excel.

## مشاركة مقرر واحد بين أكثر من مدرب

يدعم التطبيق مشاركة مقرر واحد بين عدة مدربين من خلال جدول عضوية باسم `course_trainers`.

آلية المشاركة:

1. ينشئ المدرب الأول المقرر.
2. يولد التطبيق رمز مقرر فريد.
3. ينسخ المدرب الأول الرمز ويرسله إلى مدرب آخر.
4. يسجل المدرب الآخر الدخول إلى حسابه.
5. يبحث المدرب الآخر عن المقرر باستخدام الرمز.
6. بعد ظهور بيانات المقرر والمدربين الحاليين، يضغط على زر الانضمام.
7. يتم ربط المدرب الثاني بنفس المقرر دون إنشاء مقرر جديد.

بهذا الشكل يكون للمقرر سجل واحد في جدول `courses`، ويكون لكل مدرب عضوية مستقلة في جدول `course_trainers`.

## طريقة الاستخدام

### إنشاء حساب

1. افتح التطبيق.
2. انتقل إلى إنشاء حساب.
3. أدخل اسم المدرب والبريد الإلكتروني وكلمة المرور.
4. بعد الدخول، ابدأ بإدخال بيانات الكلية والقسم والمقرر.

### إنشاء مقرر

1. أدخل اسم الكلية.
2. أدخل اسم القسم.
3. أدخل اسم المدرب.
4. أدخل اسم المقرر.
5. اختر نوع الشعبة: نظري أو عملي.
6. أدخل رقم الشعبة.
7. اضغط على إنشاء الحساب.
8. سيظهر رمز المقرر الذي يمكن مشاركته.

### انضمام مدرب آخر

1. يسجل المدرب الآخر الدخول بحسابه.
2. يضع رمز المقرر في خانة البحث والانضمام.
3. يراجع بيانات المقرر والمدربين.
4. يضغط على الانضمام لهذا المقرر.
5. تظهر له نفس بيانات المقرر والمتدربين والتقييمات.

### إضافة المتدربين

يمكن إضافة المتدربين بطريقتين:

- كتابة الأسماء يدويًا.
- استيراد ملف CSV أو Excel يحتوي على بيانات المتدربين.

يدعم الاستيراد أسماء أعمدة عربية مثل:

- اسم المتدرب
- الرقم التدريبي
- الشعبة النظرية
- الشعبة العملية

ويدعم أيضًا بعض الأسماء الإنجليزية مثل:

- name
- trainingNumber
- theorySection
- practicalSection

### إضافة التقييمات

يمكن إنشاء تقييم جديد من خلال:

1. كتابة اسم التقييم.
2. اختيار نوعه: نظري أو عملي.
3. تحديد الدرجة العظمى.
4. تحديد التاريخ.
5. إضافته إلى جدول الدرجات.

### رصد الدرجات

بعد إضافة المتدربين والتقييمات، يظهر جدول درجات يسمح بإدخال درجة كل متدرب في كل تقييم. يقوم التطبيق بحساب:

- مجموع النظري.
- مجموع العملي.
- المجموع الكلي.

### تصدير الدرجات

يمكن تصدير كشف الدرجات إلى Excel. يحتوي الملف على:

- بيانات الكلية والقسم.
- اسم المدرب.
- مدربي المقرر.
- اسم المقرر.
- رمز المقرر.
- نوع الشعبة ورقمها.
- بيانات المتدربين.
- الدرجات والتقييمات.
- المجاميع.

## البنية التقنية

التطبيق مبني باستخدام:

- React
- TypeScript
- Vite
- Cloudflare Worker كطبقة API عازلة
- Supabase خلف طبقة الخادم فقط
- CSS عادي
- lucide-react للأيقونات
- read-excel-file لقراءة ملفات Excel
- write-excel-file لتصدير ملفات Excel

## الملفات الأساسية

- `src/main.tsx`: واجهة التطبيق والمنطق الرئيسي للتفاعل.
- `src/api.ts`: عميل الواجهة الداخلي الذي يستدعي `/api` فقط.
- `src/courseData.ts`: دوال تجهيز بيانات المقرر والمتدربين والدرجات.
- `src/storage.ts`: التعامل مع طبقة `/api` للحفظ والاستدعاء والانضمام للمقرر.
- `src/types.ts`: تعريف أنواع البيانات المستخدمة في التطبيق.
- `src/styles.css`: تنسيقات الواجهة.
- `scripts/create-sites-worker.mjs`: إنشاء Worker الإنتاج الذي يخدم التطبيق ويمرر طلبات `/api` إلى طبقة التخزين.

## نموذج البيانات العام

يعتمد التطبيق على كيانات رئيسية:

- `profiles`: بيانات حساب المدرب.
- `courses`: بيانات المقرر ورمز المشاركة.
- `course_trainers`: علاقة المدربين بالمقرر الواحد.
- `trainees`: بيانات المتدربين داخل المقرر.
- `assessments`: الاختبارات والتقييمات.
- `grades`: درجات المتدربين في كل تقييم.

## متغيرات وأسرار النشر

في Cloudflare Worker يجب ضبط الأسرار التالية:

```bash
SUPABASE_URL
SUPABASE_ANON_KEY
```

لا تستخدم بادئة `VITE_` لهذه القيم، ولا تضعها داخل كود الواجهة. المتصفح يجب أن يتصل بنفس الدومين فقط عبر `/api`.

## تسجيل الدخول بجوجل

زر Google يبدأ من مسار التطبيق `/api/auth/google`، ثم يرجع إلى:

```text
https://sanadapp.pro/auth/callback
```

في Google Cloud Console أضف:

```text
Authorized JavaScript origins:
https://sanadapp.pro
https://www.sanadapp.pro

Authorized redirect URIs:
https://nhiylmayomuvdpvdlrjx.supabase.co/auth/v1/callback
```

وفي Supabase Authentication URL Configuration أضف:

```text
https://sanadapp.pro/*
https://www.sanadapp.pro/*
```

## ملاحظات مهمة

- يجب أن يكون لكل مقرر رمز فريد.
- يمكن لأكثر من مدرب الانضمام إلى نفس المقرر باستخدام الرمز.
- حفظ البيانات يعتمد على طبقة تخزين آمنة مرتبطة بالحساب.
- عند حفظ مقرر موجود مسبقًا، يتم تحديث بيانات المقرر دون تغيير منشئه الأصلي.
- عند محاولة المدرب الانضمام إلى مقرر مرتبط به مسبقًا، يعرض التطبيق رسالة توضح ذلك.

## حالة المشروع
