# نشر سند والتحقق من رحلة المستخدم

التاريخ: 5 أكتوبر 2026. الحالة: التحقق النهائي قيد التنفيذ.

دُمج طلب الإصلاحات #2 إلى main عند dd427648b24e5c1a7f604951207f97ebb3afe1fe. نشر ربط Cloudflare المباشر نسخة الموقع: /assets/index-Dc2qyFi-.js، وطابق ملف JavaScript أثر بناء GitHub حرفيًا. نجح رفض الوصول المجهول إلى واجهات الحساب ومساحة العمل والمقررات، وصفحة الخصوصية متاحة.

فشلت مهمة النشر الإضافية في GitHub لغياب CLOUDFLARE_API_TOKEN. أُزيل مسار النشر المكرر، وحل محله تحقق بعد النشر يقارن الحزمة العامة بأثر البناء ويختبر واجهات البيانات الخاصة. ربط Cloudflare المباشر هو مسار النشر القائم.

أثناء التجربة الفعلية نجح الدخول وإنشاء مقرر وإضافة متدربين بأرقام ذات أصفار بادئة، وحفظ درجتين 17 و15 ثم استرجاعهما بنفس الترتيب. نجح العثور على الدعوة وانضمام الحساب الثاني، لكن ظهرت ملاحظات إضافية قبل إتمام الرحلة:

- عند فراغ الملف الشخصي، كانت تفاصيل المدرب التي أدخلها عند الانضمام تختفي رغم حفظها في العضوية. يسترجع الخادم الآن التفاصيل من عضوية المدرب إذا كان ملفه الشخصي فارغًا.
- كان مؤقت الحفظ التلقائي يبقى قائمًا بعد الحفظ اليدوي، ويغيّر إصدار المقرر دون تعديل جديد. يُقارن الآن محتوى البيانات بآخر نسخة حُفظت فعليًا؛ تُلغى الكتابة المكررة وتبقى التعديلات التي تحدث أثناء الطلب غير محفوظة إلى حين طلب مستقل. فشل الحفظ التلقائي أصبح ظاهرًا بدل إخفائه.
- كان saved_at يعتمد على الوقت القديم المرسل من الواجهة؛ يُضبط الآن وقت الحفظ الفعلي في الخادم.

التحقق من الإصلاحات الإضافية: 185 اختبار وحدة، و12 اختبار Worker، و17 فحص متصفح للحفظ والبيانات والتصدير وإتاحة الاستخدام، كلها ناجحة محليًا. اختبارا المؤقت يستخدمان ساعة متصفح افتراضية واستجابات API محاكاة للتحقق من المدة دون انتظار ثلاث دقائق فعلية.

ضغط تصدير Excel عبر ربط المتصفح التفاعلي لم يُنتج حدث تنزيل يمكن للأداة التقاطه؛ هذا لا يثبت فشل البرنامج. التحقق النهائي من الملف سيتم في جلسة اختبار مستقلة تقتصر على الحسابين المؤقتين وبياناتهما، دون فتح سجل تنزيلات المستخدم.

سيبقى الإطلاق معلّقًا حتى نشر هذه الإصلاحات الإضافية وإتمام الرحلة الفعلية وقراءة ملف التصدير والتحقق من الخروج وتنظيف الحسابات المؤقتة.
