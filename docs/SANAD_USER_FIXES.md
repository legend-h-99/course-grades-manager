# إصلاح أخطاء تجربة المستخدم في سند

5 أكتوبر 2026. الإصلاحات تخص النسخة المرشحة في طلب الدمج #2؛ لا يثبت هذا التقرير نشرها على sanadapp.pro.

| الخطأ المرصود | الإصلاح والتحقق |
|---|---|
| الخروج يبقي بيانات المقرر ظاهرة | إصلاح طلب الخروج موجود في الفرع؛ تُمسح الجلسة والبيانات محليًا حتى عند فشل الخادم، وتظهر رسالة توضح الفشل. تحقق متصفح من ذلك في Chrome وFirefox وWebKit. |
| رمز المشاركة الأول يتغير ويصبح غير صالح | عرض ونسخ رمز الدعوة الذي يرجعه الخادم فقط، وإعلان نجاح إنشاء المقرر بعد اكتمال الحفظ. لا يُعرض معرّف المقرر الداخلي كرمز دعوة. تحقق الإنشاء والرمز بعد إعادة التحميل. |
| الرقم والاسم يدخلان معًا في الاسم | دعم الرقم ثم مسافة ثم الاسم، مع بقاء دعم الفاصلة والفاصلة العربية وTab والأسماء وحدها. المحافظة على الأصفار البادئة والأرقام العربية، وإضافة مثال واضح. |
| نسبة نجاح 100% دون تقييمات | عدم حساب/عرض إحصائيات النجاح دون تقييمات، وإظهار طلب إضافة تقييم. |
| نص زر الاستدعاء غير مرئي | تثبيت لون النص والخلفية في بطاقة الحفظ الداكنة، مع فحص الكمبيوتر والجوال وإتاحة الاستخدام. |
| البريد غير الصحيح يرسل طلبًا | التحقق من صيغة البريد في الواجهة وجميع حالات استخدام المصادقة، ومنع طلبات الدخول والرمز والاستعادة عند عدم صحة الصيغة. الاستعادة والرمز لا يفرضان كلمة مرور. |
| ترتيب المتدربين يتغير بعد الاسترجاع | حفظ موضع كل متدرب في sort_order واسترجاعه بهذا الترتيب بدل الفرز على الاسم المشفّر؛ تحقق عبر حفظين يعيدان تشفير الأسماء. |

## التحقق الحالي

- 185 اختبار وحدة ناجحًا.
- 11 اختبار Worker ناجحًا، منها اختبار حفظ الترتيب واسترجاعه خلال دورتين.
- 15 فحص Chrome ناجحًا: حالات الإصلاح، إتاحة الاستخدام على الكمبيوتر والجوال، التصدير إلى Excel حتى 500 متدرب × 20 تقييمًا، المجاميع، وفشل الحفظ والخروج.
- 5 حالات الإصلاح الأساسية ناجحة في Firefox، و5 ناجحة في WebKit. هذه متصفحات مكتبية؛ لا تعادل أجهزة جوال فعلية.
- البناء وفحص الأنواع، فحص الاعتماديات (صفر ثغرات معلنة)، وتجهيز النشر دون نشر ناجحة.
- اختبارات المتصفح الحالية تستخدم استجابات API محاكاة؛ اختبارات Worker تختبر المسار المولّد. لم تُعد هذه الجولة اختبار البريد أو Google الحقيقيين، أو اختبار ضغط الإنتاج.

طُبقت الهجرة الإضافية preserve_trainee_order على Supabase. لا تحذف بيانات قائمة، والنسخة القديمة تتجاهل العمود الجديد. ترتيب الإدخال التاريخي غير المسجل لا يمكن استعادته؛ يثبت الترتيب الموجود عند أول حفظ بالنسخة الجديدة.

امتلأت مساحة الجهاز خلال تكرار الفحوص، فحُذفت نسخة Firefox المؤقتة التي نزّلها الوكيل لهذه الاختبارات وأُعيدت الفحوص المتأثرة بنجاح.

## حالة النشر

الإصلاحات محفوظة في الفرع codex/cloudflare-release-readiness وطلب الدمج #2. صلاحيات Cloudflare OAuth الحالية تشمل Pages وتفتقد Workers؛ لم يُنفذ نشر فعلي بهذه الصلاحيات. يجب توفير صلاحية نشر Workers، ثم نشر النسخة والتحقق من هذه الحالات على الموقع العام قبل اعتبار أخطائه معالجة.
